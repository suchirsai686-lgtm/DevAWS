# AWS Student Community Day — Tirupati 2026 Frontend

React + Vite + Tailwind CSS scaffold based on the supplied feature document.

## Run
```bash
npm install
npm run dev
```

## Important
- Replace placeholder event data in `src/data/eventData.js`.
- Set the confirmed event date/time for the countdown.
- Replace speaker, sponsor, team, gallery, venue, social and registration placeholders.
- Keep ticket/payment logic on KonfHub or the confirmed ticketing provider.
- The component structure is intentionally section-based so sections can be reordered independently.
